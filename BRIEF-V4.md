# Brief v4: five upgrades (owner picked). NOT AR.
App: branded Creality Ender-3 live-data 3D parts catalog (this repo). Keep Mainstay branding (tokens/fonts in CSS), all honesty labels (BOM/LIVE/UNVERIFIED, no invented data), GPL model credits, routes (/part/:id, /01/:gtin), live APIs, window.__catalog hooks, existing tests + verify assertions. No email addresses anywhere.

1. Scan-to-part
- "Scan" button (header on desktop; prominent on phone, e.g. next to Parts) opens a full-screen scanner sheet: getUserMedia({video:{facingMode:'environment'}}) with playsinline/muted video (iPhone Safari requirement), decode frames with a QR lib (use `jsqr` on canvas frames; optionally BarcodeDetector when available, fall back to jsqr). Torch-free. Viewfinder overlay in brand style, clear permission-denied / no-camera / insecure-context states with a "paste or type a link/GTIN" fallback input.
- Parse scanned text with a pure module `src/scan.ts` → `parseScan(text, origin)` returning {kind:'part', id} | {kind:'gtin', gtin} | {kind:'cart', ...} | {kind:'unknown'}. Accept: this app's `/part/<id>` URLs (any host matching origin or gs1-3d-catalog-poc.vercel.app), GS1 Digital Link URIs on ANY host with `/01/<8-14 digit GTIN>` (+ qualifiers like /10/LOT, /21/serial, query strings), bare GTIN digits, element string `(01)xxxxxxxxxxxxxx`, raw GS1 element string `01xxxxxxxxxxxxxx...` (FNC1 \x1d separators), and cart share URLs. Validate GTIN check digits. On success: close scanner, haptic (navigator.vibrate if available), navigate as the route would. Unknown → toast with what was read.
- Printable QR sheet page at `/qr-sheet` (also linked from About/footer + scanner): grid of all 17 parts, each card: part name, category, Creality BOM codes (mono), QR of `${origin}/part/<id>` labeled "App deep link (not a GS1 Digital Link — no public GTIN)", plus print header with Mainstay logo (logo is white → on print use dark-on-light treatment: CSS filter invert for print or the MD mark on a dark chip) and instructions. Print CSS: white background, black text, A4/Letter friendly, 2–3 per row, page-break-inside: avoid, hide app chrome; screen view in brand dark with a "Print" button.

2. Guided intro
- First-run overlay (~10 s total, 3–4 short steps auto-advancing ~2.5 s each, or tap to advance): "Drag to orbit · pinch to zoom", "Tap any part to see BOM + live prices", "Explode to reach hidden parts", "Scan a part QR". Point at real UI elements (spotlight/pulse). Dismissible (Skip / X / tap outside / Esc), remembered in localStorage (`gs1catalog.introSeen.v1`), replayable from a "Tour" / "?" button. Must not block deep links (if opened via /part or /01 or a cart link, delay or skip intro). Respect prefers-reduced-motion. Verify script must set localStorage to skip intro before existing assertions, plus one test that it shows on first run and can be dismissed.

3. Exploded view animation
- Smooth eased glide (e.g. easeInOutCubic, ~900 ms) apart and back, interruptible mid-animation (toggle reverses from current position), per-part direction vectors from model center plus sensible manual offsets so hidden parts become reachable: mainboard/control panel + case fan out of the sheet-metal enclosure (enclosure top/bottom move away), PSU out, hotend/fans out of the carriage, extruder, motors, bed rises, Z-axis etc. Selecting a hidden part while assembled should auto-explode or fade others so it is visible (keep fade toggle). Camera framing updates to exploded bounds. Expose `window.__catalog.explodeProgress` (0..1) for tests. Verify: after explode, mainboard projects to a visible on-screen point and a tap on it selects 'mainboard'.

4. Price compare
- Where to buy: sort control (Best match / Lowest price) default "Lowest price in stock": in-stock first, then ascending price, grouped by currency — NEVER compare across currencies; if listings have mixed currencies, show a note "Prices in N currencies — compared within each currency only (no conversion)" and give a "Best price" badge to the cheapest in-stock listing per currency. Out-of-stock and null-price listings at the end. Pure module `src/price.ts` (`sortListings`, `bestPriceIds`) with unit tests.
- Keep the UNVERIFIED compatibility note; badge text "Lowest listed price" or "Best price" + small "(in stock, <CUR>)".

5. Shareable cart (no backend)
- "Add to list" button on each part sheet (toggle; shows count), and optionally per listing "Add this listing". A "List" drawer (header button with count badge): items = parts (qty editable 1–99, default 1, initial from BOM qty optional NO — default 1), each showing the current cheapest in-stock live listing per currency (fetched live via /api/offers when the drawer opens; loading/error states), link out to that listing, remove, clear. Subtotals per currency only (no cross-currency total), labeled "Live prices fetched <time>; not a checkout".
- State in localStorage. Share: encode list into URL `/list?i=<compact>` (e.g. `hotend.1,psu.2`; part ids validated; versioned `v=1`), copy-link button + `navigator.share` when available. Opening a /list URL restores the list (merge or replace with a prompt-less "Replaced your list" toast + undo), opens the drawer, fetches live prices. Pure module `src/cart.ts` (`encodeCart`, `decodeCart` robust to junk/unknown ids/duplicates/qty bounds) with unit tests. Cart share URLs are also accepted by the scanner.
- Make sure the vercel.json SPA rewrite covers /list and /qr-sheet (it already rewrites non-api/models/assets paths).
